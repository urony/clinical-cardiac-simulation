# ממשק ניהול מקרים (מקומי)

דף שרץ על המחשב שלך בלבד ומאפשר להוסיף מקרה חדש: לתאר אותו, להפיק טיוטה בעזרת AI, לעבור עליה ולערוך, ולהוסיף אותו לאתר. הוא **לא** חלק מהאתר הציבורי, ומורים לא יכולים להגיע אליו.

## הפעלה

```bash
npm run admin            # עם AI אמיתי (צריך מפתח, ראו להלן)
npm run admin -- --demo  # הדגמה: טקסט דוגמה, בלי AI ובלי עלות, ואי אפשר להוסיף לאתר
```

ואז לפתוח בדפדפן את `http://127.0.0.1:4180/` (הכתובת מודפסת). לעצירה: Ctrl+C. מומלץ להתחיל בהדגמה כדי להכיר את המסכים.

## ארבעה שלבים

1. **תיאור המקרה.** טופס בעברית חופשית: נושא ואבחנה, מטרות למידה, המטופל, אנמנזה, בדיקה גופנית, בדיקות, החלטות וטיפול. בנוסף **תלונה מרכזית** (מה שהתלמיד רואה לפני הפגישה, ללא אבחנה). הכול נשמר אוטומטית.
2. **הפקת טיוטה.** בוחרים ספק ומוסיפים מפתח API (נשמר בזיכרון של השרת המקומי בלבד, לא בקובץ, ולא מוחזר לדף). מוצגת תוכנית: כמה קריאות למודל (כ-15). אפשר גם **טיוטה ריקה** ולמלא ידנית.
3. **סקירה ועריכה.** כל הגיליונות (פרטי המקרה, אנמנזה, בדיקה גופנית, תוצאות מספריות, בדיקות בסיסיות, בדיקות המשך, החלטות, כללי משוב). אפשר לסנן "רק פריטים לבדיקה" או "רק ריקים". פריט שה-AI סימן (צהוב) חייב לקבל וי "בדקתי את הפריט". עריכות נשמרות לבד.
4. **בדיקה והוספה לאתר.** מוצגת רשימת מה חוסם. ההוספה אפשרית רק כש: אין שגיאות בדיקה, כל הפריטים המסומנים אושרו, יש תלונה מרכזית, וסימנת "בדקתי את התוכן הקליני ואני אחראי עליו". אחרי הלחיצה נכתבים הקבצים בפרויקט (ללא commit ולא פרסום).

## אחרי ההוספה

בחלון הפקודות, בתיקיית הפרויקט:

```bash
npm test
git add data && git commit -m "Add CASE-004" && git push
```

האתר הציבורי מתעדכן אחרי ה-push (כדקה-שתיים).

## מה נכתב ולאן

- `data/cases/case-004.json` ורשומה ב-`data/cases/index.json`.
- `data/source/case-004-patient-database-he.xlsx`: עותק Excel של המקרה, אם Python עם openpyxl נמצא (אחרת נוצר רק ה-JSON, והממשק מציין זאת).
- טיוטות ועריכות בתיקייה `drafts/` (לא נכנסת ל-git).

## בטיחות

- השרת מאזין רק ל-127.0.0.1, כל קריאה דורשת אסימון אקראי שנוצר בכל הפעלה, ובקשות מאתרים אחרים נדחות.
- המפתח לא נכתב לדיסק ולא מודפס. הוא נעלם כשסוגרים את השרת.
- שום דבר לא מגיע לנתוני האתר בלי אישור מפורש שלך אחרי בדיקה תקינה.
- ה-AI ממלא טיוטה בלבד. הבדיקה מבנית ולא רפואית: **אחריות הנכונות הקלינית שלך**.

## מגבלות

- **לא הורץ מול ספק AI אמיתי.** נבדק עם מודל מזויף בלבד (כולל מעבר מלא עד הוספה). ההרצה הראשונה צריכה להיות בסקירה מלאה.
- הממשק משתמש בתבנית הקיימת: אותן שאלות, בדיקות גופניות ורשימות בדיקות (33 בסיסיות, 9 בדיקות המשך). הוספת פריטים חדשים (למשל למקרה לא קרדיאלי) תדרוש הרחבה של התבנית; ראו התכנון בשיחה.
- הכותרת והדוגמאות באתר עדיין קרדיולוגיות.
- ההפקה ב-Gemini החינמי תלויה במכסה היומית שלך; ההפקה נעצרת עם הודעה ברורה אם נגמרה.
